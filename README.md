# Оренда квартир

Застосунок має дві окремі частини, кожна зі своїм входом:

| Частина | Адреса | Що є |
|---------|--------|------|
| Клієнтська | `/` | каталог квартир (місто, пошук, фільтри за кімнатами й ціною), реєстрація й вхід, кабінет |
| Менеджерська | `/manager` | вхід для менеджерів, квартири (список, редагування), окрема сторінка «Додати квартиру» |

Пароль змінюється в самому застосунку: у менеджера — пункт меню «Змінити пароль», у клієнта — розділ «Кабінет».

Клієнти реєструються самі (`/register`). Менеджерів самостійно зареєструвати не можна — перший менеджер створюється
при першому запуску сервера: **manager@rental.ua / manager123** (змініть через змінні середовища
`MANAGER_EMAIL` і `MANAGER_PASSWORD` до першого запуску або поміняйте пароль у базі).

## Запуск

Потрібен Node.js ≥ 20.

```bash
npm install
npm install --prefix client
npm run dev          # API на http://localhost:3001
npm run client       # інтерфейс на http://localhost:5173 (у другому терміналі)
```

Для одного сервера: `npm run build --prefix client`, потім `npm start` — Express віддасть і API, і інтерфейс.

Змінні середовища: `PORT`, `DB_FILE`, `SESSION_SECRET` (секрет підпису сесій; інакше створюється файл
`database/.session-secret`), `COOKIE_SECURE=1` (для HTTPS).

## База даних (SQLite, `database/rental.db`)

- `apartments` — квартири (`schema.sql`);
- `apartment_photos` — фото квартир (до 12 на квартиру, перше — головне), файли лежать у теці `uploads/`;
- `users` — облікові записи, роль `client` або `manager`, пароль зберігається як scrypt-хеш;

Таблиця `users` описана в `accounts.sql` і додається до існуючої бази автоматично при старті —
дані квартир не змінюються. `npm run db:init` створює базу заново (дані зникають), `db:check` перевіряє обмеження.
Таблиця `clients` залишилась у схемі, але в інтерфейсі більше не використовується.
